## Hey, I'm Kaique 👋

I'm a developer from São Paulo, Brazil 🇧🇷 who can't stop building things: little tools, web and mobile apps, weird experiments, and whatever idea shows up at 2am. Most of them end up here, open source and free to use.

I also run **Stackvision**, a small software studio where I build custom systems for businesses.

### 🛠️ What I'm into

- 🌐 Web apps with **React**, **TypeScript** and **Vite**
- 📱 Mobile apps with **React Native** and **Expo**
- ⚙️ Backends and APIs with **C#** and **Node.js** + **Express**
- 🗄️ Databases with **SQL Server** and **MySQL**, shipped with **Docker** and **Azure**
- ✨ Interactive, animated interfaces (yes, sometimes with **three.js**)
- 🎮 Scripting in **Lua** for game servers, just for fun
